## Qu'est-ce que NuxiPro ?

NuxiPro est un gestionnaire de tâches minimaliste et léger, sans fonctionnalités inutiles qui encombrent votre espace de travail. Son objectif principal est de créer un **espace de travail auto-nettoyant** — les tâches qui atteignent "Terminé" sont archivées automatiquement.

La plupart des outils Kanban facilitent l'ajout de tâches et de fonctionnalités, mais aucun ne garde votre espace de travail propre et sans encombrement. NuxiPro résout ce problème.

## Le problème

Les outils actuels nous aident à ajouter des tâches, mais aucun ne nous aide à les retirer. Sans nettoyage automatique, la colonne "Terminé" devient un cimetière de cartes. On perd un temps précieux à chercher comment archiver et à nettoyer manuellement, au lieu de faire avancer son projet.

J'ai construit NuxiPro pour proposer un Kanban simple, minimaliste, prêt à l'emploi. Dès qu'une tâche glisse dans la colonne "Terminé", elle est instantanément archivée en arrière-plan. Configuration minimale, zéro complexité, et votre tableau reste propre dès le premier jour.

## Comment ça marche

- **Archivage instantané (démo) :** Les tâches s'archivent instantanément lorsqu'elles sont déplacées vers Terminé. Les données restent dans votre navigateur (localStorage).
- **Archivage configurable (cloud) :** Choisissez votre mode d'archivage — instantané ou temporisé (X jours). Stockage serveur persistant.

## Fonctionnalités clés

- **Zéro friction** — L'archivage manuel disparaît complètement
- **Zéro encombrement visuel** — Plus de tâches terminées qui polluent votre espace de travail
- **Suivi simple** — Visualisez votre progression et vos victoires quotidiennes, sans effort
- **Aucune fonctionnalité inutile** — Concentrez-vous sur l'essentiel sans être submergé
- **Démarrage rapide** — Un outil prêt à l'emploi, simple au quotidien

## Démo vs Cloud

| | Démo | Cloud |
|---|---|---|
| Mode d'archivage | Instantané uniquement | Instantané ou temporisé |
| Stockage des données | localStorage du navigateur | Côté serveur (persistant) |
| Usage prévu | Découverte | Production, usage quotidien réel |
| Compte requis | Non | Oui |

## NuxiPro Cloud — Bientôt disponible

La version Cloud de NuxiPro ([app.nuxipro.com](https://app.nuxipro.com)) est actuellement en développement.

### Ce que proposera NuxiPro Cloud

- **Stockage sécurisé des données** — Vos données sont stockées dans une base de données, pas dans le localStorage du navigateur
- **Souveraineté des données** — Vous restez propriétaire de vos données, toujours
- **Support multi-projets** — Chaque projet apparaît comme une ligne dans la barre latérale avec son propre nom
- **Archivage automatique des tâches terminées** — Les tâches terminées sont déplacées automatiquement vers l'archive
- **Outils minimalistes** — Aucune fonctionnalité inutile que vous n'utiliserez jamais
- **Compte dédié** — Un compte par utilisateur
- **Espaces de travail** — Basculez entre vos espaces de travail sans perdre de temps
- **Configuration réduite** — Choisissez votre mode d'archivage à la configuration, changez-le à tout moment

### Comment fonctionne l'archivage dans Cloud

Deux modes au choix :

- **Instantané** — La tâche s'archive immédiatement lorsqu'elle est déplacée vers "Terminé"
- **Temporisé** — La tâche s'archive après X jours (configurable)

Vos tâches sont visuellement séparées de votre espace de travail. Les tâches terminées passent dans une zone d'archive dédiée, sans être chargées à l'ouverture de votre projet — ce qui évite les problèmes de performance.

Votre espace de travail reste propre, sans encombrement visuel dû aux tâches terminées. Vous pouvez toujours retrouver vos tâches archivées dans la zone d'archive, sans jamais les perdre.

### Pourquoi la démo n'est pas faite pour de vrais projets

La démo est conçue uniquement pour la démonstration. Si vous y stockez des données sensibles, vous risquez de les perdre définitivement car le stockage se fait dans votre navigateur (localStorage). La version Cloud résout ce problème grâce à un stockage serveur persistant.

## Démo vs Cloud

| | Démo | Cloud |
|---|---|---|
| Stockage des données | localStorage du navigateur (peut être perdu) | Base de données (persistant) |
| Mode d'archivage | Instantané uniquement | Instantané ou temporisé |

| Espaces de travail | Non | Oui |
| Compte | Non | Oui |
| Configuration | Aucune | Choix du mode d'archivage à la configuration |
| Usage prévu | Découverte | Production, usage quotidien réel |
